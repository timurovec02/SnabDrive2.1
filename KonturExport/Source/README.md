# KonturExport 1.3.1 — Яндекс → Избранное → Excel

Готовая Windows x64 сборка и исходники C# / .NET 8 / Playwright. Теперь запускается **установленный Яндекс Браузер**, а не Chrome for Testing. Расширения разрешены. Ваш основной профиль Яндекса не используется.

## Полный маршрут по вкладкам

1. `homeTab`: стартовая `about:blank` используется для https://zakupki.kontur.ru/ → прямая кнопка «Войти». Лишняя пустая вкладка не создаётся.
2. `authTab`: захваченная новая вкладка входа → «Сертификат» (если список ещё скрыт) → «Титов Андрей Николаевич».
3. После Титова **та же вкладка авторизации может перейти в закупки**: скрипт продолжает в ней. Также поддерживаются новая рабочая вкладка и возврат в главную → «Избранное».
4. Основная кнопка выгрузки → диалог → подтверждение → ожидание Download → постоянное сохранение Excel.

Новые вкладки отслеживаются **до клика**, но появление новой после сертификата НЕ обязательно. Проверяются только страницы текущего входа и новые страницы шага; посторонние старые вкладки не используются. Подробная схема и дерево всех файлов находятся в **FLOW.md**.

## Исправления 1.3.1

`about:blank` может кратко отображаться сразу при запуске браузера — это нормальное начальное состояние. Теперь эта стартовая страница используется для загрузки Контура, а не остаётся пустой рядом с новой вкладкой. Вкладки с уже открытыми сайтами автоматически не закрываются.

Ошибка 1.3.0: скрипт ждал обязательную третью вкладку. Исправлено: навигация существующей вкладки не является событием создания страницы, поэтому рабочая страница определяется по адресу Контура и доступности «Избранного» в текущей вкладке входа или новой странице.

## Быстрый запуск

1. **Распакуйте обновлённый архив целиком в новую папку.** Не удаляйте DLL и `.playwright`.
2. Яндекс Браузер должен быть установлен на компьютере. Выполните **CheckBrowser.cmd** — он покажет найденный `browser.exe` и его версию.
3. Если браузер не найден или нужна конкретная ГОСТ/корпоративная установка, откройте **Settings.cmd** и задайте `BrowserExecutablePath` (пример ниже).
4. Если нужен Контур.Плагин, один раз выполните **SetupPlugin.cmd** и установите/включите браузерное расширение **в открытом этим скриптом окне**. Если расширение не нужно для входа по почте/SMS, этот шаг можно пропустить.
5. Запустите **Start.cmd**. Если вкладка сертификата уже открыта, программа сразу нажмёт первую видимую надпись **«Титов Андрей Николаевич»**. Если список скрыт — сначала откроет **«Сертификат»**. SMS для этого маршрута не ожидается. После успешного входа продолжит автоматически; PIN токена, если он запрошен, вводится вручную в системном окне.
6. Программа дождётся кабинета в той же или новой вкладке, переключится на рабочую страницу и перейдёт в «Избранное», откроет выгрузку, подтвердит диалог и сохранит Excel. Дождитесь сообщения **«ГОТОВО. Сохранён файл»**.

Готовый EXE содержит .NET Runtime: **.NET SDK, Visual Studio и PowerShell 7 для запуска не нужны**. Яндекс и системный Контур.Плагин в архив не входят и автоматически не устанавливаются. Браузер Chromium для обычного запуска не скачивается.

> Приложение не подписано цифровым сертификатом. Исходники есть в `Source`. Не отключайте защиту Windows или антивирус ради запуска.

## Путь к Яндексу

По умолчанию `BrowserExecutablePath` пустой: программа проверяет обычные каталоги пользовательской/системной установки Яндекса, дополнительные каталоги `YandexBrowser*` и App Paths Windows. Автоматической подмены Яндекса другим браузером нет.

Через `Settings.cmd`:

```json
"BrowserExecutablePath": "%LOCALAPPDATA%\\Yandex\\YandexBrowser\\Application\\browser.exe"
```

Либо укажите свой полный путь, например:

```json
"BrowserExecutablePath": "C:\\Program Files\\Yandex\\YandexBrowser\\Application\\browser.exe"
```

Это примеры, а не гарантированные пути вашей установки. Если установлены обычный и ГОСТ-Яндекс, для выбора конкретного укажите его реальный `browser.exe`. Обратные слеши в JSON удваиваются.

Разовый выбор:

```bat
KonturExport.exe --browser "C:\полный\путь\browser.exe" --check-browser
```

`CheckBrowser.cmd` проверяет наличие файла и показывает версию, но **не подтверждает совместимость Playwright или работу криптоплагина**.

## Контур.Плагин и расширения

В запуске используется `ExecutablePath`, а канал `chromium` не задаётся. Из стандартных аргументов Playwright исключены только:

```text
--disable-extensions
--disable-component-extensions-with-background-pages
```

Остальные аргументы не отключаются целиком. Проверка HTTPS не отключается. **Песочница включена через ChromiumSandbox = true:** аргумент `--no-sandbox` не добавляется в рабочий запуск Яндекса. Предупреждение не маскируется отключением панели уведомлений.

**SetupPlugin.cmd** открывает каталог «Контур.Расширение» и официальную справку Контура в том же отдельном профиле, который будет использоваться для выгрузки. Установку и необходимые разрешения подтверждаете вы. При недоступности каталога можно выбрать другой каталог из официальной инструкции Контура.

Для полной работы могут потребоваться две части:

- Системный **Контур.Плагин** — устанавливается в Windows отдельно по инструкции Контура. Обычные установщики скачивайте и запускайте через свой обычный браузер, а не через окно автоматизации с временными файлами Playwright.
- Браузерное **Контур.Расширение** — устанавливается/включается именно в профиле автоматизации через **SetupPlugin.cmd**.

Расширение из вашего обычного профиля Яндекса **не копируется** в профиль программы. Если расширение в новом профиле уже есть, устанавливать повторно не нужно.

[Официальная инструкция Контура](https://support.kontur.ru/extern/51473-obyazatelnye_programmy).

Программа **не устанавливает системные криптокомпоненты, не вводит PIN токена и не подписывает документы**. Окна КриптоПро/токена не являются обычными HTML-диалогами Playwright. Первоначальную настройку и проверку электронной подписи делайте в видимом режиме.

## Авторизация по сертификату (1.3.1)

Последовательность при необходимости входа: сайт Контура → прямая кнопка «Войти» → **«Сертификат»** → **«Титов Андрей Николаевич»** → проверка кабинета → прежняя выгрузка Excel. Вкладка авторизации привязана к событию после «Войти»; после сертификата отслеживается её перенаправление, возврат в главную и появление новой рабочей страницы. Посторонние старые вкладки не подхватываются. «Сертификат» ищется как кнопка/вкладка/ссылка; ФИО — как видимый текст или имя элемента карточки.

Настройки уже заполнены:

```json
"UseCertificateLogin": true,
"SingleCertificateExpected": true,
"CertificateButtonName": "Сертификат",
"CertificateOwnerName": "Титов Андрей Николаевич",
"CertificateOwnerSelector": "",
"CertificateLoginTimeoutSeconds": 90
```

Если сохранённая сессия уже работает, повторная авторизация пропускается, как раньше. Программа не выходит из аккаунта автоматически. Если требуется именно новый вход, выйдите из аккаунта вручную и запустите Login.cmd.

Если список уже открыт, нужен только клик по владельцу. Повторно нажимать вкладку не требуется. SMS не запрашивается программой и отдельного шага ожидания SMS нет. Enter для обычного успешного входа **не требуется**. Если токен запросит PIN, введите его в системном окне. При изменившемся интерфейсе или таймауте останется резервный ручной шаг с Enter.

По вашему уточнению сертификат один, а ФИО показано на его карточке дважды. При `SingleCertificateExpected: true` выбирается **первая видимая надпись с точным ФИО**, повторный текст не считается вторым сертификатом. Другой владелец не выбирается. Если в будущем появится несколько сертификатов с тем же ФИО, установите `SingleCertificateExpected: false` для строгого выбора либо задайте точный CSS `CertificateOwnerSelector` по вашему codegen. Для CSS-переопределения также проверяется соответствие текста указанному ФИО. Сертификаты и PIN в проект не включены; ключи и операции подтверждает установленный криптокомпонент.

`UseCertificateLogin: false` возвращает резервную ручную авторизацию. Не меняйте владельца на случайный и не включайте скрытый режим до проверки видимого входа с установленным плагином.

## Постоянный профиль

Новый профиль по умолчанию:

```text
%LOCALAPPDATA%\KonturExport\yandex-profile
```

Профиль прежней сборки `browser-profile` не переносится и не удаляется. Первый вход в новом профиле выполняется вашим сертификатом. Это намеренно: не используем профиль другой версии/марки браузера и не затрагиваем основной личный профиль Яндекса.

- **Login.cmd** — открытие авторизации с новым маршрутом «Сертификат» → указанный владелец; дополнительные подтверждения вручную.
- Программа не хранит пароль или SMS: вводите их на странице Контура.
- Включайте сохранение входа / запоминание устройства, если сайт их предлагает.
- Не закрывайте окно браузера до сообщения об успешном сохранении.
- Не запускайте два экземпляра программы с одним профилем.
- Не указывайте основной личный профиль Яндекса в `ProfileDirectory`.
- Профиль содержит секреты сессии: не отправляйте его и не добавляйте в Git.
- Срок доверенного входа определяет Контур. Для описанного вами сертификатного входа отдельного шага SMS нет.

## Папка Excel

По умолчанию:

```text
%USERPROFILE%\Downloads\KonturExports
```

Параметр в `settings.json`:

```json
"OutputDirectory": "D:\\Kontur\\Excel"
```

Или разово:

```bat
KonturExport.exe --output "D:\Kontur\Excel"
```

Готовые файлы называются `Избранное_дата_время_идентификатор.xlsx` (либо `.xls` для старого формата). Файл сначала сохраняется как `.part`, проверяется по содержимому и переименовывается. HTML/JSON-ошибка не выдаётся за XLSX; для диагностики она остаётся как `.bin`.

GUID в списке загрузок браузера — временное имя Playwright. Открывайте копию по пути из сообщения `ГОТОВО`, не временную запись в браузере.

## Что сохранено в алгоритме

- Постоянный контекст живёт до завершения скачивания и `SaveAsAsync`.
- Viewport 1920×1080 для показа «Избранного»; клика по «Дополнительной навигации» нет.
- Download перехватывается **до первого клика**, во всех вкладках и новых popup.
- Основная кнопка и подтверждение диалога нажимаются по одному разу.
- Поддерживаются прямое скачивание и уже открытый диалог.
- Закрытие экспортного popup после получения файла не мешает сохранению, если контекст браузера остаётся жив.

Названия `FavoritesName` и `ExportButtonName` взяты из вашего codegen. Избранное ищется как `Link`, выгрузка как `Button`, подтверждение внутри `Dialog`. Если сайт изменит роли, нужно обновить `LoginFlow.cs` / `ExportFlow.cs`. Для наведения на правую панель можно задать реальный CSS-селектор в `RightSidebarSelector`.

## Ошибки и автоматический режим

**Logs.cmd** открывает журналы в `%LOCALAPPDATA%\KonturExport\logs`. Сохраняются события открытия/закрытия вкладок, шаг выгрузки, имя файла и путь. Параметры ссылок авторизации вырезаются. Скриншоты ошибки по умолчанию выключены; если включить `CaptureScreenshotOnError`, они могут содержать личные данные.

**RunUnattended.cmd**: `--headless --no-pause`. Используйте только после успешного видимого запуска. Для криптоплагинов и системных окон скрытый режим может не подходить — не включайте его без проверки. Если требуется новый вход по сертификату, используйте видимый `Login.cmd`. Запускайте от того же Windows-пользователя; избегайте параллельных запусков.

Коды завершения: `0` — успех / завершение выбранного режима; `1` — ошибка; `2` — нужен интерактивный вход.

## Исходники и тесты

`Source\KonturExport.sln` / `.csproj`. Для самостоятельной сборки нужен .NET 8 SDK или новее с поддержкой net8.0, интернет для NuGet. **Source\Build.cmd** создаёт самостоятельную Windows x64 сборку в `Source\publish`.

```bat
dotnet run -- --check-browser
dotnet run -- --setup-plugin
dotnet run -- --login
dotnet run -- --self-test
```

Только для разработчика: браузерные тесты выполняются на локальных страницах с тестовым Chromium, а не Яндексом:

```bat
dotnet run -- --install-test-browser
dotnet run -- --self-test-browser
```

## Граница проверки

Яндекс — Chromium-совместимый сторонний браузер, но отдельного официального канала Playwright `yandex` нет. Используется запуск по `ExecutablePath`; совместимость конкретной установленной версии необходимо проверить у вас. Сборка и локальные тесты HTML-модели не подтверждают работу Яндекса на вашей Windows, системного Контур.Плагина, сертификата или аккаунта Контура. Реальные страницы списка сертификатов здесь недоступны.

В этой среде нет вашей Windows-установки Яндекса, сертификатов и SMS. Доступ по тарифу, изменения закрытой страницы и дополнительные проверки сервиса могут потребовать ручного действия. Программа не обходит ограничения.
