## Что исправлено

В 1.3.0 ошибочно ожидалась обязательная третья вкладка. Теперь проверяется навигация самой вкладки авторизации: событие создания новой страницы для этого не требуется.

Первоначальная пустая страница используется для Контура. Она может кратко показаться во время запуска/загрузки, но отдельная лишняя `about:blank` из-за `NewPageAsync` не оставляется. Непустые вкладки с другими сайтами не закрываются.

Проверяются только страницы текущего входа и новые страницы этого шага. Постороннее старое «Избранное» не выбирается. При действующей сохранённой сессии повторный вход пропускается. Профиль не очищается, песочница включена.
