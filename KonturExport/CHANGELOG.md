# Изменения

## 1.3.1 — перенаправление и стартовая пустая страница, 2026-10-08

- Исправлена ошибочная обязательность третьей вкладки после выбора сертификата.
- Поддерживаются та же вкладка, новый popup и callback в главную.
- about:blank используется для главной/рабочей страницы вместо создания лишней вкладки.
- Вкладки с чужими сайтами не закрываются и не используются.
- PageReuse.cs: безопасный выбор стартовой пустой страницы.
- Добавлены тесты всех трёх вариантов перехода и повторного использования about:blank.
- Сохранение Excel, выбор сертификата, песочница и профиль не изменены.

## 1.3.0 — полный маршрут по трём вкладкам, 2026-10-08

- Главная → «Войти» → захваченная новая вкладка авторизации.
- Сертификат выбирается в этой конкретной вкладке, а не во всех ранее открытых.
- Новая рабочая вкладка перехватывается до клика по владельцу; Избранное ищется только в ней.
- Старые вкладки не подменяют рабочую при новом входе.
- TabCapture.cs фиксирует новые страницы шага, FLOW.md содержит полный маршрут и дерево файлов.
- Прежняя выгрузка, сохранение, песочница и профиль не изменены.

## 1.2.1 — единственная карточка и песочница, 2026-10-08

- Повтор ФИО на одной карточке больше не блокирует вход: при одном сертификате нажимается первая видимая надпись.
- При уже открытом списке вкладка «Сертификат» не нажимается повторно.
- SMS не ожидается в маршруте авторизации по сертификату.
- Песочница включена через ChromiumSandbox=true: рабочий запуск без --no-sandbox.
- Добавлены тесты карточки с двумя ФИО и уже активной вкладки.
- Выгрузка Excel и профиль не изменены.

## 1.2.0 — сертификат, 2026-10-08

- Новый маршрут входа: «Сертификат» → «Титов Андрей Николаевич».
- Оба клика выполняются автоматически в веб-интерфейсе, включая popup.
- После успешного входа Enter не нужен: продолжается прежняя выгрузка.
- PIN/SMS и системные окна остаются ручными; другой/неоднозначный сертификат автоматически не выбирается.
- Добавлены параметры ФИО, вкладки, точного CSS-переопределения и ожидания результата входа.
- Активная сохранённая сессия используется как раньше; выход/очистка профиля не выполняются.
- Файлы выгрузки и запуска Яндекса не изменены.

## 1.1.0 — Яндекс, 2026-10-08

- Вместо Chrome for Testing запускается установленный Яндекс через ExecutablePath.
- Добавлены поиск browser.exe в стандартных каталогах/App Paths и BrowserExecutablePath для явного выбора.
- Нет автоматического перехода на другой браузер, если Яндекс не найден.
- Расширения разрешены: отключающие их стандартные аргументы исключены.
- Новый отдельный yandex-profile; старый browser-profile и основной личный профиль не изменяются.
- CheckBrowser.cmd: проверка пути/версии без запуска.
- SetupPlugin.cmd: видимый запуск профиля для ручной установки браузерного расширения Контура.
- Обычный запуск больше не скачивает Chromium. Его установка оставлена только для тестов разработчика.
- Добавлены проверки выбора браузера, настроек расширений и запуска по ExecutablePath.
- Исходники и готовая Windows x64 сборка включены в обновлённый архив.
