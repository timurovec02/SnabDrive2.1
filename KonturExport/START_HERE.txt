KonturExport 1.3.1 — пустая вкладка и перенаправление исправлены.

Распакуйте новый архив целиком в новую папку. Запуск: Start.cmd.

1. Стартовая about:blank используется для загрузки Контура, а не остаётся пустой.
2. Контур → Войти → вкладка авторизации → Сертификат → Титов Андрей Николаевич.
3. После Титова рабочая страница может загрузиться В ЭТОЙ ЖЕ вкладке.
   Программа не требует открытия третьей вкладки. Новая вкладка и возврат
   в главную также поддерживаются.
4. Избранное → Выгрузить в Excel → диалог → подтвердить → сохранить файл.

about:blank может кратко появиться перед загрузкой; лишняя пустая вкладка не оставляется.
Непустые вкладки не закрываются. Старое постороннее Избранное не выбирается.
Сертификат один, повтор ФИО допустим. SMS не ожидается; PIN токена вручную, если запрошен.
Профиль/песочница/сохранение Excel остаются прежними. Профиль не очищается.

Путь браузера и папка Excel: Settings.cmd. Журналы: Logs.cmd. Схема: FLOW.md.
Исходники: Source; для готового EXE SDK не нужен. Реальный аккаунт здесь не проверялся.
